SECCBOT is an interactive cybersecurity awareness chatbot designed to educate users about online safety, cyber threats, and best security practices. It provides real-time responses to common cybersecurity questions and helps users recognize and avoid risks such as phishing, malware, password attacks, and social engineering.

The goal of SECCBOT is to make cybersecurity education simple, accessible, and engaging for everyday users.Interactive chatbot for cybersecurity awareness
Educates users on safe online practices
Explains common cyber threats (phishing, malware, scams)
Provides quick security tips and best practices
Beginner-friendly explanations for non-technical users
Fast response system for real-time interaction
